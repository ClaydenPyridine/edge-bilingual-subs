# 双语字幕 · English → 中文（Edge 扩展）

抓取网页视频的**英文字幕轨**，实时翻译成中文，在画面上以「英文 + 中文」两行对照显示。

方案 D 的第一阶段：**有字幕就直取，不做语音识别**。所以延迟低、几乎零成本。

---

## 安装（30 秒）

1. 打开 Edge，地址栏输入 `edge://extensions`
2. 右下角打开 **「开发人员模式」**
3. 点 **「加载解压缩的扩展」**
4. 选择这个文件夹：`edge-bilingual-subs`
5. 装好后点扩展图标 → **「扩展选项」**，配置翻译引擎（见下）

> 自己用不需要上架商店，开发者模式加载就够。

---

## 配置翻译引擎

打开设置页有两种引擎：

### ① 浏览器内置翻译（推荐，免费离线）
Edge 158 内置了 `Translator` API，英文→中文在本地完成，**不花钱、不联网、不用密钥**。
设置页顶部会自动检测并告诉你是否可用。

### ② DeepSeek API（内置不可用时兜底）
- 在设置页填 **密钥**（`sk-...`）和模型（默认 `deepseek-chat`）
- 密钥只存在你本机浏览器存储里，只会发往你填的接口地址
- 你 DSH 里已经有一个 `DEEPSEEK_API_KEY`，从 DSH 的凭据文件（`$DSH_HOME/.credentials.yaml` 的 `refs` 段）复制即可

填完点 **「测试翻译」** 验证一下。

## 用法

1. 打开 YouTube 视频（或任何带英文字幕轨的页面）
2. 视频播放时，字幕会**贴在视频画面底部**出现
3. **点扩展图标** = 开关字幕
4. 设置里可调：是否显示原文、中文字号、**底部距离（占视频高度的百分比）**

字幕会提前 90 秒的窗口做预翻译，所以不会「说完才出字」。

### v0.5 更新（语音识别 + 右下角控制条 + 字幕放大）

**字幕条放大**
- 默认中文字号 `22px → 30px`（设置里可拉到 64px）
- 字幕条宽度放开到画幅的 96%，不再是一小条
- 老配置会自动迁移一次，不会被旧的 22px 盖住

**右下角控制条**
- 贴在视频右下角的小胶囊：`● 语音字幕 · 开 / 关`
- 开启时红色圆点呼吸，点击即开关
- 插件默认开启（`asrEnabled: true`）

**语音识别（ASR）—— 没有字幕轨也能出双语字幕**

```
标签页音频 → tabCapture → offscreen 文档
  → 16kHz 单声道 PCM → 能量 VAD 切句（1.5–8 秒一段）
  → POST /audio/transcriptions（OpenAI 兼容）
  → 英文文本 → DeepSeek 翻译 → 回传页面 → 双语浮层
```

支持的 ASR 服务（任选，填在设置里）：

| 服务 | 接口地址 | 模型 | 说明 |
|---|---|---|---|
| **Groq**（推荐） | `https://api.groq.com/openai/v1` | `whisper-large-v3-turbo` | 快、便宜 |
| OpenAI | `https://api.openai.com/v1` | `whisper-1` | 稳定 |
| 本地 faster-whisper | `http://127.0.0.1:8000/v1` | `Systran/faster-whisper-base.en` | 免费，密钥留空 |

> ⚠️ **DeepSeek 目前没有语音识别接口**，它的账号只能用来做翻译。

**启动需要一次手势**
浏览器的安全限制：`tabCapture` 必须在用户点击扩展图标后才能启用。所以**第一次启动请点工具栏上的扩展图标**；之后右下角胶囊就能自由开关了。

### v0.4 更新（过滤音效标注）

自动字幕里夹着 `[Music]`、`[Applause]`、`(upbeat music)`、`♪ ♫` 这类**非人声标注**，翻出来只是噪音。

现在默认过滤掉，规则：
- `[...]` / `(...)` / `{...}` 里含 music、applause、laughter、silence、inaudible、noise、cheer、beep、cough 等关键词的整段删除
- 音符符号 `♪ ♫ ♬ ♩` 删除
- 清理后只剩标点或空白的条目整条丢弃

如果某条字幕是「他说着话[Music]又说了句」，只会删掉方括号那段，人话保留。
设置页可以关掉这个过滤（**过滤音效标注**）。

### v0.3 更新（修「两行中文」）

**问题**：YouTube 的字幕被设成「自动翻译成中文」时，播放器请求的 `timedtext` 带 `tlang=zh-Hans`，返回的**本身就是中文**。扩展把它当英文原文抓走，于是原文位和译文位显示同一句中文。

**修复**：三层过滤 + XML 兜底
1. URL 带 `tlang=` 的一律丢弃
2. `lang` 参数不是 `en*` 的丢弃
3. 文本里含 CJK 字符（`\u3400-\u9FFF`）的丢弃
4. json3 解析不出来时，退回解析老式 XML 字幕；再不行才安静等待网络钩子

### v0.2 更新

- **浮层改为贴合视频画面**：不再固定吸在窗口底部。扩展每帧读取 `<video>` 的 `getBoundingClientRect()`，把字幕盒子精确盖在画面上，所以**非全屏时也在视频正下方**，全屏时自动铺满。
- **底部距离改成百分比**：`10%` 意味着距离视频底边 10% 高度，全屏和窗口化会等比缩放。觉得挡住播放器控制条就调到 `15%`～`20%`。
- **适配 bilibili**：会递归进 `shadowRoot` 找 `<bwp-video>` 内部的 `video` 元素。
- **状态标签只在出错时出现**（`no-english` / `track-empty` / `track-error`），4 秒自动消失，不再常驻显示 `navigated`。
- **翻译不可用会明确提示**：没配密钥且内置翻译不可用时，会提示「请到扩展选项里填 DeepSeek 密钥」。

## 工作原理

```
YouTube 页面 (MAIN world)
  ├─ 读 ytInitialPlayerResponse 里的 captionTracks
  │    → 找 en 轨 → fetch timedtext&fmt=json3 → 解析成 cue
  └─ 兜底 hook fetch/XHR 里所有 /api/timedtext 响应（直播走这条）
                    │
                    │ window.postMessage
                    ▼
隔离世界 content.js
  ├─ 收 cue，按 start 排序去重
  ├─ requestAnimationFrame 对齐 video.currentTime
  ├─ 提前 90 秒批量翻译（内置 Translator 或 DeepSeek）
  └─ 渲染浮层（跟随全屏，pointer-events:none 不挡鼠标）
```

非 YouTube 站点会尝试读页面原生 `<track>` 元素（同源字幕有效，跨域会失败）。

## 已知限制（诚实说明）

| 限制 | 说明 |
|---|---|
| **只支持英文字幕** | 按你的要求，暂不做俄/法/日 |
| **必须有字幕轨** | 没有英文字幕的视频不会工作（阶段 2 才上 ASR） |
| **YouTube 直播** | 需要播放器里**打开 CC**，扩展才能拦到流式字幕 |
| **DRM 站点** | Netflix 等加密内容拿不到字幕/音频，不适用 |
| **跨域 `<track>`** | 多数站点的字幕文件带 CORS 限制，读不到 |
| **内置翻译质量** | 离线模型对长句和口语会有点生硬，不如 DeepSeek |
| **bilibili** | 播放器适配已经做了（能正确贴到画面上），但 B 站自带字幕基本是中文轨，**英文字幕很少**，所以多数视频不会有字幕输出。英文内容建议直接在 YouTube 看。 |
